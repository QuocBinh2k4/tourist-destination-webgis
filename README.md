
# TOURISMGIS

Hệ thống quản lý và phân tích không gian
các điểm du lịch trên nền tảng WebGIS.

## Công nghệ

Frontend: React, Vite, Leaflet

Backend: Node.js, Express

Database: PostgreSQL, PostGIS

Version Control: Git, GitHub

## Chức năng dự kiến

1. Quản lý điểm du lịch
2. Quản lý loại hình du lịch
3. Quản lý cơ sở dịch vụ
4. Tìm kiếm và lọc dữ liệu
5. Hiển thị bản đồ WebGIS
6. Phân tích vùng đệm Buffer
7. Tìm kiếm trong bán kính
8. Đánh giá khả năng tiếp cận dịch vụ

## Cấu trúc

frontend: Giao diện người dùng

backend: API và xử lý nghiệp vụ

database: Cơ sở dữ liệu PostGIS

docs: Tài liệu dự án
